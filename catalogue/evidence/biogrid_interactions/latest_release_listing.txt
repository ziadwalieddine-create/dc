 BioGRID Release 5.0.262 
 This download directory contains the 5.0.262 interaction data release from the BioGRID. 
 This release was compiled on Sept. 25th, 2026 and contains all curated interaction data processed 
 prior to this date. If you are starting 
 a new project using our data, it is HIGHLY recommended that you use the data files in the most recent release 
 as it will contain the most up-to-date version of our interaction dataset. The best dataset to use is in the CURRENT RELEASE directory. 
 For more information about each of the available files, simply mouse over to see a description. 
 To download each file, simply left click on it to start the download process.
