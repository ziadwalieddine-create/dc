PharmVar Terms and Conditions

PharmVar provides data downloads of allele definitions for all genes that have been incorporated into the PharmVar database. Data can be downloaded either from the gene page or from the tool above. Allele definitions are available in the following formats:

FASTA

FASTA downloads contain the nucleotide sequence representing the allele. FASTA sequences will be the based on the primary locus reference sequence (RefSeqGene or LRG) for the gene. The allele sequence will start at the first base of the locus reference sequence (usually approximately 5kb upstream of the ATG start) and will continue until the end of the reference sequence (usually approximately 2kb downstream of the stop codon). The allele sequence will contain all variants defined for the haplotype.

FASTA sequences will have a header line that includes the haplotype identifier, the reference sequence the haplotype sequence is based on and the PharmVar version. An example for the CYP2C9*5B haplotype is as follows:

CYP2C19*5B NG_008384.3 pharm-var-1.3

Variant Call File (VCF)

Allele definitions are provided in VCF format where the entire file represents the differences between the requested allele and a specific reference sequence (e.g. the locus reference sequence or the relevant chromosomal reference sequence in a genome build). VCF files are presented in VCF 4.2 format. Variant positions in the VCF file will always be based on counting the first nucleotide of the locus sequence as position 1 (i.e. Sequence Start).

Tab Separated Values (TSV)

Allele definitions are provided in a tab-separated file with one line per haplotype/variant combination. This means that for haplotypes containing multiple variants, the haplotype definition will take up multiple lines in the file. Similarly, variants that appear in multiple haplotypes will appear multiple times in the file. Haplotype variants will be grouped together sequentially and sorted by position. Like VCF files, variant positions will always be based on counting the first nucleotide of the reference sequence as position 1 (i.e. Sequence Start). TSV files have a header as the first line of the file that defines the following columns:

haplotype identifier (name)
gene symbol
dbSNP rsID (if applicable)
reference sequence
variant start
variant stop
reference allele
variant allele
variant type

As an example, using this format, the CYP2C9*1B haplotype, defined by a two base deletion and a substitution compared to NG_008385.1, would be represented as follows:

CYP2C9*1B CYP2C9 rs71486745 NG_008385.1 2363 2364 TG - deletion

CYP2C9*1B CYP2C9 rs4918758 NG_008385.1 3838 3838 T C substitution

Special Cases / Exclusions
Reference alleles (*1)

Alleles that represent the wildtype reference (e.g. *1 of most genes) and that have no variants defined for them will have the following special cases in the downloads

FASTA: The resulting sequence will be identical to the locus reference sequence.

VCF: No VCF file is provided for haplotypes that have no variants on a selected reference sequence. Note that the reference haplotype may have variants defined in the context of a difference reference sequence. For example, the CYP2D6 reference gene sequence has multiple differences when compared to the GRCh37 genome build. In this case, a VCF file for the reference haplotype is available for the GRCh37 reference sequence.

TSV: A single entry for the reference haplotype is listed in the TSV file. This entry has ‘REFERENCE’ under the reference allele column and ‘.’ in the variant allele column.

Structural variants and complex variant types

Haplotypes defined by structural variation, including rearrangements and large deletions that are not strictly defined by positional notation, are not included in the downloads currently.

RefSeqTranscript

Downloads are not available for transcript reference sequences. This is due to complications in accurately representing the sequence produced in cases where variants in the haplotype interrupt splicing behavior.

Download Types

The content of the download will vary according to which download type is selected. The three types of downloads available are as follows:

Single Haplotype

These downloads are available from the gene page by clicking the download icon  next to the haplotype identifier. Haplotype downloads are available in VCF or FASTA format. VCF files will contain variants for the haplotype in comparison to the currently selected reference sequence on the gene page. FASTA files will always contain a version of the locus reference sequence. Individual haplotypes downloaded from the gene page will always contain the current version of the haplotype.

Gene

All definitions can be downloaded for a single gene by clicking the ‘Download Gene Data’ button on the gene detail page. The download will consist of a .zip archive containing the following files:

multi-entry FASTA file containing all haplotype sequences for the gene
TSV file containing all haplotype definitions for the gene for each reference sequence
One VCF file for every haplotype for each reference sequence
Database

All haplotype definitions for all genes in the PharmVar database can be downloaded together from this page. Database downloads will contain all data for a single, selected version of the PharmVar database with the default being the current version. Previous versions can be selected using the select menu above. The full database download consists of a .zip archive containing the following files:

multi-entry FASTA file containing all haplotype sequences for the gene
one TSV file for each gene containing all haplotype definitions for the gene on a specific reference sequence, one file for each reference sequence
VCF files for every haplotype in every gene for each reference sequence

The database zip archive is organized into directories by gene and reference sequence. An abbreviated example structure of the archive is as follows:

pharm-var-1.3/

CYP2C9/

CYP2C9.haplotypes.fasta

RefSeqGene/

CYP2C9.NG_008384.3.tsv

CYP2C9_1B.vcf (one file per haplotype)

GRCh37/

CYP2C9.NC_000010.10.haplotypes.tsv

CYP2C9_1B.vcf (one file per haplotype)

GRCh38/

CYP2C9.NC_000010.11.haplotypes.tsv

CYP2C9_1B.vcf (one file per haplotype)
