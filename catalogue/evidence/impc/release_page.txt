Release notes

Represents a major data release.

This release includes:

Approximately 4.5 million more data points.
The release contains 2,139 fewer phenotype calls than the previous release due to the removal of duplicated Histopathology and Gross Pathology phenotypes.
The data reports have been restructured to ensure they are machine readable and outdated links have been updated. In addition, several data issues have been fixed for the viability and procedureCompletenessAndPhenotypeHits reports. Please see the README file for more information.
This release uses an updated annotation pipeline that improves MP term assignment for sex specific terms.
A procedure sequence_id was included for metadata group determination in minispec data from GMC for late adult pipelines to enable grouping of the appropriate datasets for analysis and display on the website.
Links to the Tremblay lab early lethal phenotype data have been added.
