 
 Database of Genomic Variants [*** dgv ***] A curated catalogue of human genomic structural variation About the Project Genome Browser Downloads Query Tool Links Submissions Statistics Contact Us FAQ Training Resources Download Data The contents of the Database of Genomic Variants can be downloaded as tab delimited text files. The first line of each file is the column description. Each variant is provided with an accession which is a stable identifier and will remain constant. Studies where CNV coordinates are based on a newer assembly are not mapped back to older builds. The NCBI Build 36 (hg18) download file will therefore contain less data than the GRCh37 (hg19). We have provided three categories of files for users to download. The first set of files, contained in the "DGV variants" section, represents the data that is displayed in our primary DGV structural variants track. The second set of files, in the "Supporting Variants" section, are the sample level and supporting variants that are displayed in our Supporting Variants track. The last section is the "Filtered Variants" files. These are variants that have been removed from the database following our curation process. Note that for the DGV Variants and Supporting Variants sections, a new file has been made available under the "Other Mappings" column. These files contain those variants that do not map to the reference assembly but instead to an alternate sequence/contig assembly.
