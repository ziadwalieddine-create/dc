 Filter interactions based on the combined confidence score: While all links in STRING are meaningful, some analyses might require only higher-confidence interactions, excluding the more exploratory part of the interaction spectrum. This can reduce file sizes by up to 90%. Note: Confidence scores in the files below are multiplied by 1000. 
 All interactions (0.150) Medium confidence (0.400) High confidence (0.700) Highest confidence (0.900) 
 Remove redundant interaction pairs (AB-BA): By default, the links files encode interactions in both directions (AB and BA). However, since functional and physical interactions are symmetric, recording them once (AB) is sufficient without losing information. This reduces links file sizes by 50%. This does not apply to regulatory links, where column order signifies directionality (A->B). 
 Includes AB and BA pairs Includes AB pairs only
